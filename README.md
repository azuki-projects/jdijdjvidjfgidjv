# Crypto Trading Simulator
Virtual-money only crypto simulator. Start with $10,000. Market prices update gradually every 2.5 seconds, with adjustable movement scale (0.05%, 0.1%, 0.2%, 0.3%). Portfolio, trades, prices and settings persist in data.json.

## Start
```bash
npm install
npm start
```
Visit http://localhost:3000. Uses process.env.PORT and binds to 0.0.0.0 for hosting.
